# toronto-weather-data-visualization-
Toronto Weather Data Visualization is a project aimed at analyzing and visualizing historical weather data for Toronto. This project provides insights into weather patterns and trends using interactive charts and graphs.

## Features
- Data cleaning and preprocessing of raw weather datasets.
- Interactive visualizations for temperature, precipitation, and other weather metrics.
- Support for time-series analysis and trend identification.

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/DaveFan25/toronto-weather-data-visualization-
    ```
2. Navigate to the project directory:
    ```bash
    cd toronto-weather-data-visualization
    ```
3. Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Usage
1. Use Jupyter Notebook to visualiza the data 

## Requirements
- Python 3.8 or higher
- Libraries: pandas, matplotlib, plotly (see `requirements.txt` for the full list)
